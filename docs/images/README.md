## Capture tips

- **Use non-personal data.** Seed a few demo contexts or use an empty vault — these images go public.
- Use `Win + Shift + S` (Windows) for clean rectangular crops.
- Keep all shots in the **same theme** (Volt) for a consistent look.
- Aim for ~1400px wide PNGs; GitHub scales them down crisply.
- Optional: replace `hero.png` with a short `demo.gif` of the capture → summarize flow for extra impact (update the README `<img>` src if you do).
