Install the browser extension
Follow the four steps below — copy the folder path when you reach step 4.
  1. Open the Extensions page Copy chrome://extensions (or edge://extensions in Edge) into your browser's address bar and press Enter.
  2. Enable Developer mode Find the Developer mode toggle in the top-right corner of the page and switch it on. A new row of buttons will appear below.
  3. Click "Load unpacked" It's the leftmost button in the row that just appeared. A folder picker will open.
  4. Select the extension folder Click Copy below, then paste the path into the picker's address bar (or browse to it manually) and click Select Folder.
    E:\ConVX\extension
