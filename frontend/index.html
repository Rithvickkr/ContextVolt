ConVX as MCP Server checking…

External LLMs (Claude Desktop, Cursor, ChatGPT, Grok…) can read your saved vault through Model Context Protocol. Two transports — pick whichever your tool supports.

Cloudflare Tunnel (HTTPS) stopped
Required for Grok, ChatGPT, Claude.ai — creates a free public HTTPS URL for your local server. No account needed. URL changes on restart.

cloudflared (~40 MB) is downloaded once and cached. Your vault stays on your machine — only the /mcp endpoint is exposed, protected by your bearer token.

HTTP / SSE (local network) Direct HTTP — only reachable on this machine or your local network without a tunnel.

Send as Authorization: Bearer <token> header. Regenerating revokes the old token immediately.

Off only if you're 100% sure the port is loopback-only. Off + tunnel = your vault is public.

Stdio (local-only) For Claude Desktop's Developer pane, Cursor, Claude Code.
